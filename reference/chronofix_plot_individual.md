# Plot estimated date distributions for an individual

Plot the posterior distribution of estimated dates for each event for a
single individual.

## Usage

``` r
chronofix_plot_individual(samples, id, min_window = 7, share_y_axis = FALSE)
```

## Arguments

- samples:

  A `chronofix_mcmc_samples` object as generated by
  [`chronofix_mcmc()`](https://mrc-ide.github.io/chronofix/reference/chronofix_mcmc.md)

- id:

  The id of the individual to be summarised

- min_window:

  Minimum number of days shown either side of the observed date in each
  panel. Panels are wider if the plotted dates extend further (default
  7)

- share_y_axis:

  Logical, indicating whether or not the y-axis (representing the
  posterior probability) is shared across panels. If shared across
  panels then its limits will be `c(0, 1)`. Default is `FALSE`.

## Value

A ggplot object showing the distributions of estimated dates for an
individual
