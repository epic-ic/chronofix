# Summarise an individual

Summarise the estimated dates for an individual

## Usage

``` r
chronofix_summarise_individual(samples, id)
```

## Arguments

- samples:

  A `chronofix_mcmc_samples` object as generated by
  [`chronofix_mcmc()`](https://mrc-ide.github.io/chronofix/reference/chronofix_mcmc.md)

- id:

  The id of the individual to be summarised

## Value

A list
